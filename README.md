# Hybrid Lab

Quellcode von [hybrid-lab.org](https://hybrid-lab.org) – Astro, gehostet auf GitHub Pages.

```bash
npm install
npm run dev      # lokal unter http://localhost:4321
npm run build    # statische Seite nach dist/
```

Artikel liegen als Markdown in `src/content/artikel/`. Push auf `main` → automatisches Deployment.
